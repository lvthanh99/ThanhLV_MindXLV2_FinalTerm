# Todo App

A small task manager built with React, Vite, Ant Design, and Tailwind CSS.

## Getting started

```sh
npm install
npm run dev
```

## Available scripts

- `npm run dev` starts the development server.
- `npm run build` creates a production build in `dist`.
- `npm run preview` serves the production build locally.
- `npm run lint` runs ESLint.

Tasks can be filtered by **All**, **Active**, and **Completed**. New tasks can
be added from the **All** and **Active** tabs. Completed tasks can be deleted
individually or cleared together from the **Completed** tab.
